# Modern Filipino Slang Glossary

Common conversational slang (mostly Manila/online usage). Map these to their meaning before you interpret intent. Keep them in dubbing output when the source register is casual.

Many terms come from **syllable reversal** (*baliktad*): *idol* → *lodi*, *malupit* → *petmalu*, *mismo* → *omsim*, *tara* → *arat*. When an unfamiliar word appears, try reading it backwards.

| Slang | Origin | Meaning |
|---|---|---|
| *charot* / *char* | — | just kidding |
| *echos* | — | nonsense; just kidding |
| *lodi* / *lods* | *idol* reversed | idol; term of admiration |
| *petmalu* | *malupit* reversed | awesome, impressive |
| *werpa* | *power* reversed | power; "you got this" |
| *omsim* | *mismo* reversed | exactly, for real |
| *arat* | *tara* reversed | let's go |
| *sana all* / *sanaol* | *sana* + *all* | "I wish that were me too" |
| *awit* | — | expression of disappointment ("ouch", "sad") |
| *jowa* | — | boyfriend/girlfriend |
| *besh* / *beshie* / *bes* | *best friend* | close friend |
| *mars* / *pars* | *kumare* / *kumpare* | close friend (female / male) |
| *keri* | English *carry* | can handle it; okay |
| *G* / *game* | — | willing, down for it |
| *gora* | — | go; let's do it |
| *chika* | — | chat, gossip |
| *ganern* | *ganoon* | like that |
| *shookt* | *shocked* | shocked |
| *nakakaloka* | *loka* (crazy) | maddening, unbelievable |
| *kilig* | — | giddy romantic thrill |
| *gigil* | — | overwhelming urge (to squeeze, pinch, etc.) |
| *tampo* | — | sulking from hurt feelings |
| *sus* | — | expression of disbelief |
| *edi wow* | *e di* + *wow* | sarcastic "good for you" |
| *amats* | *tama* reversed (+ *-s*) | being high or intoxicated (*may amats*, *walang amats*). Whisper drops the *-s* (*amat*) |

## Euphemisms (Body and Health)

Everyday indirect terms that show up in casual talk and memes. Recognize them; do not translate them literally.

| Term | Literal | Meaning |
|---|---|---|
| *datnan* / *dinadatnan* | "to be arrived upon" | to get / be having one's period |
| *may dalaw* | "has a visitor" | having one's period |
| *regla* / *mens* | (Spanish / English clipping) | menstruation |
| *nagnanapkin* | *nag-* + *napkin* | uses sanitary napkins |

## Quarrels, Cheating and Sarcasm

Fight scenes (teleseryes, films, vlogs) lean on a small set of idioms. When the story is a breakup, cheating or a family fight, test garbled words against this list first. The sound still decides between them (see the "Sound beats story" gotcha in SKILL.md).

| Term | Literal | Meaning |
|---|---|---|
| *sumawsaw* / *nakisawsaw* | dipped (into sauce) | cheated on a partner; also butted into someone else's business |
| *kating-kati* | itching badly | eager for a new partner (*Ba't ba kating-kati kang palitan ako?*) |
| *pinasukan* | entered | went into it (a relationship with someone); reviewer-confirmed word, sense from context (*Ah, kaya pinasukan mo?*) |
| *pinatulan* | responded to (a provocation) | stooped to someone's level, engaged with them; not the same as *pinasukan* |
| *mang-aagaw* | snatcher | someone who steals another's partner |
| *kapalit-palit* | replaceable | easy to swap out (*Kapalit-palit ba ako?*) |
| *chukchakan* | — | slang for sex |
| *bawat hininga't utot* | every breath and fart | every little thing about someone (*alam ko bawat hininga't utot niya*) |
| *hugot* / *hugots* | pulled out | deep-seated hurt, an emotional line drawn from it; English speakers keep the word |
| *Ikaw na!* | you're it | sarcastic "fine, you win / you're perfect"; often opens a list (*Ikaw na 'yung tama, ako na 'yung mali…*) |
| *Ah, ganon?* / *Eh ano ba?* | oh, like that? / so what? | sarcastic retorts |
| *Mmm* (+ a statement) | — | sarcastic agreement in an argument (*Mmm, kaya ko rin, 'no?*) |
| *Eh ikaw!* | well, you! | turning the accusation back; the *eh* is what makes it a retort |
| *Awat na!* / *Tama na!* | stop the fight / enough | pleas from a third party or the weaker side; usually layered under someone else's shouting |

## Curses and Exclamations

Curses are common in memes and fights, and they are often the joke. Transcribe them verbatim. The same speaker often switches between variants in one outburst (*Tangina naman! … Ampota!*), so a second garbled burst is not automatically a copy of the first.

| Term | Notes |
|---|---|
| *putangina* / *tangina* / *tang ina* | the most common curse; Whisper writes *Tanginala*, *Tangi na lang*, *Pag-tangin*, *muntang* |
| *puta* / *pota* / *ampota* / *amputa* | short forms (*ampota* ← *ang puta*); often the last, loudest word of an outburst |
| *putcha* / *putek* / *pucha* | softened (minced) forms |
| *punyeta*, *leche* / *letse*, *lintik* | exasperation |
| *gago* / *gaga*, *ulol* / *ulul*, *tarantado*, *bwisit*, *hayop* | insults aimed at a person |
| *mura* / *magmura* / *minura* | "a curse" / "to curse". *Mura pa!* ("curse some more") is a sarcastic reply that confirms the line before it held a curse. *Mura* also means "cheap", so decide by context |
