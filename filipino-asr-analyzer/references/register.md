# Register: Modern vs. Deep Tagalog

**Default to modern conversational Tagalog.** Recognize deep Tagalog (*malalim na Tagalog*: literary, formal, poetic, purist, or old-film dialogue), interpret it correctly, and convert it to modern equivalents. Keep the deep register only when the user asks or the source is deliberately formal (poetry, period pieces, ceremonies).

## Deep → Modern Equivalents

| Deep / formal | Modern conversational | Meaning |
|---|---|---|
| *nais* | *gusto* | want |
| *batid* | *alam* | know |
| *nawa* | *sana* | may it be / hopefully |
| *datapwat*, *ngunit*, *subalit* | *pero*, *kaso* | but |
| *sapagkat* | *kasi* | because |
| *tunay* | *totoo* | true, real |
| *iniibig* | *mahal* | loved |
| *marilag* | *maganda* | beautiful |
| *paroroonan* | *pupuntahan* | destination |
| *suliranin* | *problema* | problem |
| *mag-aaral* | *estudyante* | student |
| *pagsusulit* | *exam*, *test* | exam |
| *palikuran* | *CR*, *banyo* | restroom |
| *kasintahan* | *jowa*, *boyfriend/girlfriend* | partner |
| *pamantasan* | *university*, *unibersidad* | university |
| *salipawpaw* | *eroplano* | airplane |
| *salumpuwit* | *upuan*, *silya* | chair |
| *sipnayan* | *math*, *matematika* | mathematics |
| *dagitab* | *kuryente* | electricity |

### Sentence Example

- Deep: *Nais kong batid mo na ikaw ay aking iniibig.*
- Modern: *Gusto kong malaman mo na mahal kita.*

Note that the modern version also drops the inverted *ay* construction (*ikaw ay…*). Everyday speech prefers predicate-first order.
