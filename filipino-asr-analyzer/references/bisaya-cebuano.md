# Bisaya / Cebuano Starter Reference

Whisper has no Cebuano option, so Cebuano speech run with `--language tl` comes out spelled like Tagalog. Use this file to **recognize** Cebuano and transcribe it **in Cebuano**, never "Tagalogized". This is a starter list of common words; confirm anything uncertain with a native speaker.

## How to Spot Cebuano
- Hashtags or captions: *#bisaya*, *#bisdak*, *#cebuano*; captions using *kaayo*, *karon*, *unsa*, *dili*.
- Marker words: *kaayo* (very), *karon* (now), *unsa* (what), *asa* (where), *kinsa* (who), *ngano* (why), *dili* (no/not), *naa* (there is / is here), *wala* (none), *gyud* (really), *diay* (oh, so it's…), *lagi* (indeed), *man*, *bitaw*, *unya* (later / then), *kay* (because).
- Possessives before the noun: *akong* (my), *imong* (your), *iyang* (his/her), *among/atong* (our).

## False Friends (same spelling, different meaning)
| Word | Cebuano | Tagalog |
|---|---|---|
| *kayo* / *kaayo* | *kaayo* = very (Whisper writes *kayo*) | *kayo* = you (plural) |
| *kay* | because | marker for a person (*kay Juan*) |
| *libog* | confused | lust |
| *langgam* | bird | ant |
| *karon* | now | (*kanina* / *ngayon*) |
